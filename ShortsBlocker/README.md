# Shorts Blocker (안드로이드)

유튜브 앱의 **쇼츠 화면만** 자동으로 감지해서 뒤로가기 시켜 차단하는 안드로이드 앱입니다.
(옵션으로 크롬 등 브라우저에서 youtube.com/shorts 접속도 함께 차단)

## 작동 원리

- `AccessibilityService`가 유튜브 앱과 주요 브라우저의 화면 변화를 실시간으로 감시합니다.
- 유튜브 화면 안에서 쇼츠 전용 UI 요소(view id)를 발견하면 `GLOBAL_ACTION_BACK`을 눌러 즉시 이전 화면으로 돌려보냅니다.
- 일반 유튜브 영상 시청, 검색, 구독 피드 등은 전혀 건드리지 않습니다 — 오직 쇼츠 화면만 타겟팅합니다.

## 빌드 방법

1. [Android Studio](https://developer.android.com/studio) 설치 (최신 버전 권장)
2. `File > Open`으로 이 `ShortsBlocker` 폴더 전체를 엽니다.
3. Android Studio가 자동으로 Gradle Wrapper를 생성하고 필요한 라이브러리를 내려받습니다 (인터넷 필요, 첫 sync는 몇 분 걸릴 수 있어요).
4. 안드로이드 폰을 USB로 연결하고 개발자 옵션 > USB 디버깅을 켠 뒤, 상단의 ▶ Run 버튼을 눌러 폰에 바로 설치할 수 있습니다.
   - 또는 `Build > Generate Signed Bundle / APK`로 APK를 만들어 폰에 옮겨 설치해도 됩니다.

## 설치 후 사용법

1. 앱을 열면 "접근성 설정 열기" 버튼이 보입니다. 눌러서 이동한 뒤,
   설정 목록에서 **Shorts Blocker**를 찾아 켜주세요.
2. 접근성 권한을 요청하는 경고창이 뜨는데, 화면을 실시간으로 읽어서 쇼츠 화면을 판별해야 하므로 정상적인 동작입니다. "허용"을 눌러주세요.
3. 앱으로 돌아오면 상태가 "✅ 접근성 서비스가 켜져 있어요"로 바뀝니다.
4. 이제 유튜브에서 쇼츠 탭이나 쇼츠 영상으로 진입하면 자동으로 튕겨나갑니다.

## 차단이 안 될 때 (유튜브 업데이트로 UI가 바뀐 경우)

`ShortsBlockerService.kt`의 `shortsResourceIdHints` 목록을 최신 유튜브 앱의 view id에 맞게 갱신하면 됩니다.
확인 방법:
1. 폰 개발자 옵션에서 "레이아웃 경계 표시" 또는 Android Studio의 **Layout Inspector**를 이용해 쇼츠 화면의 view id를 확인합니다.
2. 새로 확인한 id 문자열을 목록에 추가합니다.

필요하면 이 부분을 다시 요청해 주시면 최신 값으로 갱신해 드릴게요.

## 강한 차단이 필요하면 (추가 확장 아이디어)

- **기기 관리자(Device Admin) 권한** 추가 → 앱 삭제/접근성 끄기를 비밀번호로 잠그기
- **다른 런처(홈 화면 앱) 감지** → 특정 시간대에만 차단 활성화하는 스케줄 기능
- 이런 기능이 필요하면 말씀해 주세요, 이어서 만들어 드릴게요.

## 권한 안내

이 앱은 광고, 분석 SDK, 인터넷 권한이 전혀 없습니다. 오직 접근성 서비스 권한만 사용하며, 모든 감지는 기기 안에서만 처리되고 외부로 전송되지 않습니다.
